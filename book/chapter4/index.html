4 方案 ​

4.1 方案分类 ​

4.1.1 传统方案 ​

整句型：以拼音的代表，笔画次之 字词型：以五笔的代表，自然码次之

4.1.2 乱序方案 ​

在保持键盘布局不变的情况下通过乱序来改善手感（击键当量）。这类方案有蓝宝石、虎码、龙码等。 改善手感的另一条道路是，在码元不变的情况下调整键盘布局（例如，有人就为飞单设计了新的键盘布局）。

4.1,3 前缀方案 ​

文字码 日月 清韵

4.1.4 顶功方案 ​

声笔系列：声笔易拼、声笔简拼、声笔拼音、声笔飞系、声笔象码 冰雪系列：冰雪四拼、冰雪三拼 星空系列：星空键道、星空二笔 其他

4.2 方案选择 ​

在选择方案的时候，一定要清楚方案的目标用户是谁，其的使用场景是什么。

4.2.1 目标用户 ​

4.2.2 使用场景 ​

影响输入系统的各种因素综合起来就构成了一个使用场景。这些因素包括：看打、听打还是想打，电脑还是手机，现代文还是文言文，聊天还是工作等等。常见的使用场景有下面几种。

  • 默认场景：指输入方案设计时目标场景。
  • 用户场景：用户的典型的典型使用场景，用户的匹配场景，这对于用户来说是最重要的。
  • 练习场景：
  • 竞速场景
  • 表演场景

4.2.3 方案匹配 ​

方案与使用场景和用户场景的匹配。例如，竞速的场景往往与用户场景不一致，导致竞速很快，而实际使用不理想，甚至相距甚远，因为看打和想打时获取文本的方式是不一样的，文本的内容也往往大不一样。文本失配的程度可以用交叉熵或 KL 散度来衡量。

4.3 方案对比 ​

从信息论的角度来看，不同的输入方案本质上是在不同的约束条件下，对"高效传输汉字信息"这一问题的不同解法。本节从信息论的基本概念出发，对各类输入方案进行系统的对比分析。

评估软件、模拟打字

4.3.1 评估指标体系 ​

从信息论角度评估输入方案，主要有以下几个核心指标：

1. 信息熵（信源端）

汉字信源的熵决定了编码长度的理论下界。

  • 0阶熵（字熵）：约9-10比特/字
  • 1阶熵（考虑字频）：约5-6比特/字
  • 极限熵（利用上下文）：约3-4比特/字

2. 平均码长（编码端）

输入每个汉字平均需要的按键数。

  • 全拼：约4.0-4.5键/字
  • 双拼：约2.0键/字（不含选字）
  • 五笔：约3.0-3.5键/字
  • 声笔简拼：约2.0-2.5键/字

3. 编码效率

编码效率 = 信息熵 / 平均码长（比特/键）

这个指标衡量每个按键平均承载的信息量，是评估编码方案效率的核心指标。

4. 信道容量（传输端）

考虑击键速度和手感后的实际信息传输速率。

  • 信道容量 = 击键速率 × 每键信息量
  • 实际速率还受击键当量、手指负荷等因素影响

5. 失真度（接收端）

输入过程中的"不便利性"，包括重码率、选字次数、翻页次数等。

  • 重码率：每字平均候选数
  • 选字次数：每字平均需要按多少次选字键
  • 综合失真：加权考虑各种不便因素

4.3.2 各类方案的信息论对比 ​

方案类型代表方案平均码长（键/字）每键信息量（比特）重码率（失真）学习成本理论依据
全拼搜狗拼音4.0-4.5~2.0高低拼音编码，利用上下文预测
双拼微软双拼2.0~2.5高中压缩韵母，提高键均信息量
纯形码五笔3.0-3.5~2.8低高字形编码，信息密度高
音形码自然码2.5-3.0~3.0中中音形结合，兼顾效率与易学
顶功音形声笔简拼2.0-2.5~3.5可变中低顶功机制，动态调整码长

分析说明：

  1. 全拼方案：码长最长，每键信息量最低，但是因为利用了强大的语言模型和上下文预测^24,25,30,31^，实际使用中的"有效失真"并不高。它的优势在于学习成本极低，几乎零门槛。

  2. 双拼方案：通过将韵母压缩到单键，将码长缩短了一半，每键信息量有所提升。但是重码率与全拼相当，失真度没有改善。双拼本质上是一种"信源编码"，通过重新编码来提高效率。

  3. 纯形码方案：利用汉字的字形信息，每个按键承载的信息量更高，因此重码率很低，失真度小。但是学习成本高，需要记忆大量字根。纯形码更接近"最优编码"，但是牺牲了易学性。

  4. 音形结合方案：在拼音的基础上增加形码辅助，兼顾了易学性和效率。自然码、小鹤音形等都属于这一类。这类方案在效率和学习成本之间取得了较好的平衡。

  5. 顶功方案：顶功编码的独特之处在于它的码长是可变的，失真度也是可变的。用户可以根据需要动态调整——高频字可以少打码快速顶屏，低频字可以多打码降低重码。这种自适应特性使得顶功方案在理论上能够更好地逼近率失真函数的最优边界。

4.3.3 编码效率的计算方法 ​

1. 键均信息量

键均信息量 = 汉字熵 / 平均码长

Iper_key=HL

其中 H 是汉字信息熵，L 是平均码长。

这个指标衡量的是"每个按键平均传递了多少比特的信息"，是评估编码效率的核心指标。

2. 编码冗余度

编码冗余度 = 1 - 实际编码效率 / 理论最大效率

R=1−H/Llog2⁡M

其中 M 是可用键位的数量。

冗余度反映了编码方案距离理论最优的差距。冗余度越高，说明编码的效率越低，还有提升空间。

3. 有效信息速率

考虑失真后的有效信息速率：

Reffective=H−DL+Lselect

其中 D 是失真带来的信息损失，Lselect 是选字的额外码长。

这个指标更全面地反映了实际使用中的效率。

4.3.4 顶功方案的理论优势 ​

从信息论的角度看，顶功方案相比传统方案具有以下理论优势：

1. 可变码长的自适应优化

传统编码方案的码长是固定的（或者只有少数几档），而顶功方案的码长是连续可变的。这意味着用户可以针对每个字，根据其频率、歧义度、当前语境等因素，自动选择最优的码长。

这在信息论中相当于对每个符号进行自适应的变长编码，理论上比固定长度编码更接近香农第一定理的最优下界。

2. 编码与选字的一体化

在传统方案中，编码和选字是两个分离的过程——先打编码，再从候选中选择。选字的按键（数字键、翻页键）本质上也是编码的一部分，但因为它们与主编码是分离的，所以效率不高。

而在顶功方案中，编码和筛选是一体化的——继续打码就是在筛选候选。没有额外的选字切换开销，整个过程是连续的、流畅的。

3. 渐进式解码

顶功编码支持渐进式解码——随着输入的进行，候选范围逐步缩小。这与香农的序贯译码思想是一致的。

用户可以在任意时刻决定"当前的候选已经足够好了"，然后顶屏继续下一个字。这种人机协作的方式，能够充分发挥人的判断能力和机器的计算能力。

4. 无切分歧义

顶功编码的边界是清晰的，不存在拼音输入中常见的分词歧义问题。这从根本上消除了一类重要的"编码噪声"，提高了系统的可靠性。

从有噪信道编码的角度看，这相当于降低了信道的噪声水平，从而可以在相同码长下实现更低的失真，或者在相同失真下使用更短的码长。

4.3.5 方案选择的多目标权衡 ​

从信息论的角度看，不存在绝对"最优"的输入方案，因为最优总是相对于特定的目标函数而言的。选择输入方案时，需要权衡多个目标：

1. 效率目标

  • 输入速度（字/分钟）
  • 编码效率（比特/键）
  • 信道利用率

2. 学习目标

  • 学习成本（时间、精力）
  • 记忆负荷
  • 遗忘曲线

3. 使用目标

  • 手感舒适度
  • 容错能力
  • 适应性

4. 场景目标

  • 日常聊天
  • 文稿写作
  • 专业录入
  • 移动输入

不同的用户、不同的场景，最优的方案是不同的。信息论提供了分析的框架和工具，但最终的选择还是要结合实际需求。

不过，从理论发展的趋势来看，顶功编码所代表的"可变码长、渐进解码、人机协作"的方向，是更符合信息论基本原理的，也代表了输入法技术发展的一个重要趋势。
